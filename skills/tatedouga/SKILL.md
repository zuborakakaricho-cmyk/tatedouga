# 記事から縦動画

1. 初めて使うときは、プラグインのフォルダで `npm install` と `node doctor.mjs` を実行し、足りないものがあれば、ユーザーに何を入れるか伝えてから入れる。プラグインのフォルダは `${CLAUDE_PLUGIN_ROOT}`。
2. 渡されたURLが、ユーザー自身の記事か確かめる。他人の記事なら、著作権の面で問題になりうることを伝え、作らない。
3. 台本は自分（Claude）で書く。記事を読み、次の形のJSONを `<今のフォルダ>/縦動画/<記事のURLの最後の部分>/台本.json` に保存する。
   `{"scenes":[{"say":"読み上げる文","show":"画面に大きく出す要点（20字まで）","face":"normal|komari|doya","img":記事の中の画像の番号（0から）かnull}],"by":"claude"}`
   - 場面は5〜7個、全体で50〜60秒（読み上げる文は合計420字まで）。1場面目は見る人の困りごと、最後は「詳しくはブログで」
   - 数字・名前・手順は記事にあるものだけ。記事に無いことは言わない
   - 話し手・一人称・口調は `${CLAUDE_PLUGIN_ROOT}/config.json`（無ければ config.sample.json）の speaker に合わせる
4. `node "${CLAUDE_PLUGIN_ROOT}/make.mjs" <URL> --out ./縦動画` を実行する（台本.json があれば、それを使って声・画面・動画を作る）。
5. できた mp4 の場所と長さを伝える。画面で直したいときは `npm start`（ブラウザで設定・台本の直し・作り直しができる）を案内する。
